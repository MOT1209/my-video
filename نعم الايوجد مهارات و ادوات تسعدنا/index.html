بالتأكيد، هناك أدوات ممتازة ومكتبات مفتوحة المصدر (Open-Source) صُممت خصيصاً لمساعدة المطورين على حل مشاكل الفيديوهات الطويلة، وتقسيم الصوت، والتصيير السحابي دون الحاجة لبناء كل شيء من الصفر.

إليك أفضل الأدوات والمهارات المرتبطة بـ Remotion و Next.js لتنفيذ المطلوب بنجاح:

1. أدوات ومكتبات معالجة ودمج الصوت (لحل مشكلة النصوص الطويلة)

بما أن نصوص الفيديوهات الطويلة تفوق قدرة واجهة Edge-TTS في الطلب الواحد، يمكنك استخدام هذه الأدوات لتقسيم الصوت ثم دمج النتائج تلقائياً:

  • Fluent-FFmpeg: مكتبة Node.js تتيح لك التحكم بـ FFmpeg برمجياً داخل كود Next.js لدمج ملفات الصوت (.mp3) الناتجة عن المشاهد المتعددة بسهولة، وقص الخلفيات الموسيقية لستناسب طول الفيديو الطويل.
  • أو Audio-buffer: مكتبات خفيفة تساعدك على حساب الملي ثانية الدقيق لملفات الصوت لضمان مزامنة الترجمة الذكية (Captions) بدقة دون تداخل في الفيديوهات الطويلة.

2. أدوات التصيير السحابي للفيديوهات الطويلة (Cloud Rendering)

بسبب مهلة الـ 5 دقائق القصيرة في Vercel Serverless (Timeout)، لا يمكنك تصيير فيديو مدته 10 دقائق هناك. الحل الرسمي والمدعوم بقوة هو:

  • @remotion/lambda: أداة رسمية من Remotion تتيح لك نقل عملية التصيير بالكامل إلى AWS Lambda. الميزة هنا أنها تقوم بتصيير الفيديو عبر مئات الـ "وظائف المُصغرة" (Parallel Rendering) بالتوازي، مما يعني أن فيديو مدته 10 دقائق قد يتم تصييره في أقل من دقيقة واحدة، وبسعر زهيد جداً. [1, 2]

3. ترقية الترجمة والكابشن (Advanced Captions)

في الفيديوهات الطويلة، يتعب المستخدم من القوالب التقليدية، ولإضافة ميزات متقدمة:

  • @remotion/captions: حزمة مهارات وأكواد جاهزة من مجتمع Remotion تساعدك على توليد كابشن متقدم ومتحرك متوافق تماماً مع النصوص الطويلة المأخوذة من ملفات الـ SRT أو الـ JSON الناتجة عن محرك الذكاء الاصطناعي. [3]

4. مهارات وقوالب حركية جاهزة للأبعاد الأفقية (16:9)

بدلاً من بناء تأثيرات بصرية من الصفر للفيديو الطويل، يمكنك استخدام قوالب ومكتبات حركية متوافقة مع Remotion مثل:

  • Onda UI (Ondajs): مكتبة مكونات أنيميشن مفتوحة المصدر لـ Remotion (تشبه Tailwind ولكن للفيديو) تمنحك تأثيرات دخول نصوص، حركات أشكال، وانتقالات (Transitions) احترافية جاهزة تدعم الأبعاد الأفقية والعمودية تلقائياً. [4]
  • Remotion-Scenes: مستودع يحتوي على جزيئات حركية (Particle Effects) وتأثيرات خلفية سينمائية تناسب تماماً الفيديوهات الطويلة لعرض البيانات أو الشروحات التعليمية. [5]

5. مهارة Claude Code / AI Agents المتخصصة في Remotion

بما أن مشروعك يحتوي بالفعل على مجلد .agents/ skills:

  • قامت شركة Remotion بإصدار ملف مهارات رسمي يدعى remotion-dev/skills. يمكنك تحميله لـ AI Agent الخاص بك (مثل Claude Code). هذا الملف يعطي المساعد الذكي "الكتالوج الكامل" لكيفية كتابة كود حركي سليم وتجنب أخطاء التصيير المشهورة في تطبيقك. [3]

                                                                  MASTER Prompt

Act as an expert Full-Stack Next.js developer and Remotion Video Architect.

We need to upgrade an existing Remotion + Next.js video generator platform (currently restricted to vertical 9:16 Shorts up to 60 seconds) into a hybrid multi-format system. The system must dynamicly support BOTH vertical Shorts (9:16) and long-form horizontal videos (16:9, up to 10-15 minutes).

Please implement this upgrade incrementally based on the following architectural blueprint, integration tools, and official references:

---

### 1. CORE COMPONENT & INTERACTION UPGRADES

- Modify `src/components/ShortsEditor.tsx` to add a UI selector for "Video Format" (Shorts: 9:16 vs. Long-Form: 16:9).

- Refactor the Remotion composition entry points in `src/remotion/Shorts/` to accept dynamic `width`, `height`, and `fps` props instead of using hardcoded vertical constants.

- Update constraints inside `types/shorts.ts`. Create a structural dynamic schema validation (e.g., via Zod) that shifts maxDuration, maxScenes, and text character limits conditionally based on the chosen format.

---

### 2. DYNAMIC TEXT-TO-SPEECH (TTS) CHUNKING

- Since Edge-TTS fails or chokes on massive texts required for 10-minute long videos, refactor `src/app/api/tts/` and `src/lib/edge-tts.ts`.

- Implement a logical string chunker (e.g., splitting text by scenes or sentences under 300 characters).

- Fetch TTS audio pieces and accurate word-level word timestamps parallelly or sequentially.

- Integrate the Fluent-FFmpeg tool to stitch the generated .mp3 chunks seamlessly into a single production audio track before cache upload.

  * Dependency Reference: Fluent-FFmpeg NPM (https://www.npmjs.com/package/fluent-ffmpeg)

---

### 3. SERVERLESS TIMEOUT ELIMINATION VIA CLOUD RENDERING

- Vercel serverless execution limits (max 5 minutes) cannot render complex multi-minute horizontal animations.

- Refactor the video rendering orchestration engine in `src/app/api/render/`. Bypass local Vercel Sandbox rendering for long-form requests.

- Integrate `@remotion/lambda` to delegate high-volume rendering parallelization workloads directly onto scalable AWS Lambda functions. This allows a 10-minute composition to render efficiently in under a minute by rendering chunks in parallel.

  * Technical Reference: Remotion Lambda Official Docs (https://www.remotion.dev/docs/lambda)

---

### 4. ANIMATION LAYOUTS & RE-USABLE SCENE COMPONENTS

- Integrate dynamic fluid layouts that look incredible on wide screens (16:9) just as they do on vertical stacks (9:16).

- Use modular animation toolkits and caption utilities to design cinematic motion typography that adapts gracefully across screens.

  * Animation Engine Reference: Onda UI Framework (https://github.com/degueba/onda)

  * Multi-format Scenes Toolkit: Remotion Scenes Repository (https://github.com/lifeprompt-team/remotion)

---

### 5. SYSTEM CREDIT MODEL ADJUSTMENTS

- Refactor the internal credit deduction engine inside `src/lib/credits.ts`.

- Shift from the rigid "1 Video = 1 Credit" model. Implement a tiered runtime calculation engine where vertical Shorts charge 1 Credit flat, and long-form videos charge dynamically based on total duration (e.g., 1 Credit per completed minute).

---

### 6. DEVELOPER ENVIRONMENT ENHANCEMENT

- To ensure proper semantic code compilation and zero configuration breaking errors, load the official pre-compiled AI coding engine assets into our `.agents/skills` repository layer.

  * Engineering Assistant Assets: Remotion Official AI Skills (https://github.com/remotion-dev/skills)
