# الدليل الشامل لمشاريع صناعة ومونتاج الفيديو بالذكاء الاصطناعي على GitHub

يحتوي هذا المستند على تجميع منظم لأبرز المشاريع والأدوات مفتوحة المصدر (Open-Source) المتاحة على GitHub والمتخصصة في:
- توليد الفيديوهات بالذكاء الاصطناعي.
- تحويل الفيديوهات الطويلة والأفكار إلى مقاطع قصيرة (Shorts / Reels / TikTok).
- المحررات البرمجية واستوديوهات المونتاج التلقائي.
- أدوات ومكتبات إطار العمل Remotion وتقنيات التصيير السحابي ومعالجة الصوت.

---

## 1. مشاريع تحويل الأفكار والفيديوهات الطويلة إلى مقاطع قصيرة (Shorts & Clip Automation)

### 1. OpenShorts (App)
- **رابط المشروع:** [https://github.com/mutonby/openshorts](https://github.com/mutonby/openshorts)
- **الوصف:** مشروع مفتوح المصدر (MIT) يُعتبر بديلاً شاملاً لأدوات مثل OpusClip. يضم 3 أدوات رئيسية:
  1. **Clip Generator:** اقتطاع أفضل اللحظات من الفيديوهات الطويلة وتتبع الوجوه وتوليد ترجمة مزدوجة.
  2. **UGC Video Creator:** إنشاء فيديوهات تسويقية باستخدام صناع محتوى افتراضيين ومزامنة الأصوات.
  3. **MCP Server Integration:** ربط الوكلاء الذكيين لتنفيذ عمليات التحرير والتصدير برمجياً.

### 2. OpenShorts (Kaipian - 开片)
- **رابط المشروع:** [https://github.com/jnMetaCode/openshorts](https://github.com/jnMetaCode/openshorts)
- **الوصف:** نظام إنتاج فيديوهات قصيرة يعمل بمبدأ "المحلية أولاً" (Local-First). يتيح توليد الفيديوهات بالكامل محلياً عبر ربطه بنماذج مثل Ollama (كتابة السيناريو $\rightarrow$ المشاهد $\rightarrow$ التعليق الصوت $\rightarrow$ الترجمة).

### 3. AI YouTube Shorts Generator
- **رابط المشروع:** [https://github.com/Anil-matcha/AI-Youtube-Shorts-Generator](https://github.com/Anil-matcha/AI-Youtube-Shorts-Generator)
- **الوصف:** تطبيق مفتوح المصدر يُعتبر بديلاً لأدوات Vidyo.ai وKlap وSubMagic لتحويل المقاطع الطويلة إلى فيديوهات عمودية مع الترجمة والقص التلقائي.

### 4. Purffle Shorts
- **رابط المشروع:** [https://github.com/Chamanrajragu/purffle-shorts](https://github.com/Chamanrajragu/purffle-shorts)
- **الوصف:** أداة أتمتة للقنوات بدون وجه (Faceless Channels). تقوم بتحويل الأفكار أو النصوص إلى فيديوهات قصيرة، وتتولى توليد النصوص، التعليق الصوتي، الترجمة المتزامنة، وجدولة النشر.

### 5. ShortGPT
- **رابط المشروع:** [https://github.com/rayventura/shortgpt](https://github.com/rayventura/shortgpt)
- **الوصف:** إطار عمل شهير ومتقدم لأتمتة إنشاء المحتوى المرئي. يوفر لغة تحرير موجهة للذكاء الاصطناعي (LLM-oriented video editing) لجلب الوسائط، توليد الأصوات، والتعديل الآلي.

### 6. Shortube
- **رابط المشروع:** [https://github.com/remotion-dev/shorts-customizer](https://github.com/remotion-dev/shorts-customizer)
- **الوصف:** أداة لاكتشاف المواضيع الشائعة وكتابة السيناريو وإنتاج فيديو عمودي متكامل باستخدام إطار عمل Remotion مع خيار الرفع التلقائي لليوتيوب.

### 7. ShortsCreator
- **رابط المشروع:** [https://github.com/ShortsCreator/ShortsCreator](https://github.com/ShortsCreator/ShortsCreator)
- **الوصف:** منصة تحويل النصوص والروابط والصور إلى فيديوهات قصيرة، مع دعم اقتطاع المقاطع الطويلة وتعديل التعليق الصوتي والترجمة لعدة منصات.

## 2. استوديوهات وأدوات توليد الفيديوهات الشاملة (Generative AI Studios)

### 1. Open Generative AI
- **رابط المشروع:** [https://github.com/Anil-matcha/Open-Generative-AI](https://github.com/Anil-matcha/Open-Generative-AI)
- **الوصف:** استوديو ضخم ومفتوح المصدر يتيح الوصول لأكثر من 600 نموذج ذكاء اصطناعي لتوليد الصور والفيديوهات والسينما ومزامنة الشفاه (Lip Sync) دون قيود.

### 2. Agnes Video Generator
- **رابط المشروع:** [https://github.com/lcy362/agnes-video-generator](https://github.com/lcy362/agnes-video-generator)
- **الوصف:** نظام استضافة ذاتية لتوليد الفيديو من النصوص، يُقسّم الأفكار إلى مشاهد متتابعة مع اختيار مذيع افتراضي (Digital Anchor) وتجميع الفيديو النهائي.

### 3. MoneyPrinterTurbo
- **رابط المشروع:** [https://github.com/MoneyPrinterTurbo/MoneyPrinterTurbo](https://github.com/MoneyPrinterTurbo/MoneyPrinterTurbo)
- **الوصف:** مشروع مخصص لإنتاج الفيديوهات بالذكاء الاصطناعي بنقرة واحدة تلقائياً مع توليد الصور ومسارات الصوت والترجمة بالكامل.

## 3. محررات الفيديو البرمجية وأدوات المونتاج الذكية (AI Video Editors)

### 1. OpenReel Video
- **رابط المشروع:** [https://github.com/Augani/openreel-video](https://github.com/Augani/openreel-video)
- **الوصف:** محرر فيديو احترافي يعمل بالكامل داخل المتصفح (بديل مفتوح المصدر لـ CapCut). يعتمد على WebCodecs وWebGPU ويضم مساعد ذكاء اصطناعي (AI Assistant) للتحرير بالنصوص والمخطط الزمني مباشرة.

### 2. Vibe Motion
- **رابط المشروع:** [https://github.com/GurYN/vibe-motion](https://github.com/GurYN/vibe-motion)
- **الوصف:** تطبيق يدمج بين Remotion وClaude Code لبناء واجهة سحب وإسقاط وتسهيل التعامل مع العناصر المرئية والمخطط الزمني برمجياً.

### 3. Claude Remotion Editor
- **رابط المشروع:** [https://github.com/ytrofr/claude-remotion-editor](https://github.com/ytrofr/claude-remotion-editor)
- **الوصف:** أداة حركية تتيح التحكم بمحرك أنيميشن Remotion وتعديل مشاهد الفيديو باستخدام نماذج Anthropic Claude.

## 4. أدوات ومكتبات الحركة وتصيير السحابة (Remotion Ecosystem)

### 1. Remotion Framework & Lambda
- **رابط المشروع:** [https://github.com/remotion-dev/remotion](https://github.com/remotion-dev/remotion)
- **الدليل الرسمي للتصيير السحابي:** [https://www.remotion.dev/docs/lambda](https://www.remotion.dev/docs/lambda)
- **الوصف:** الإطار البرمجي الأساسي لبناء الفيديوهات باستخدام React وTypeScript. يتيح ملحق `@remotion/lambda` تصيير الفيديوهات الطويلة بالتوازي عبر AWS Lambda بدقائق معدودة وبسعر زهيد.

### 2. Remotion AI Skills
- **رابط المشروع:** [https://github.com/remotion-dev/skills](https://github.com/remotion-dev/skills)
- **الوصف:** المستودع الرسمي لملفات إرشاد وتوجيه وكلاء الذكاء الاصطناعي (مثل Claude Code) لكتابة أكواد Remotion خالية من أخطاء التصيير وحساب الإطارات.

### 3. Onda UI (Ondajs)
- **رابط المشروع:** [https://github.com/degueba/onda](https://github.com/degueba/onda)
- **الوصف:** مكتبة مكونات أنيميشن وتأثيرات حركة مفتوحة المصدر لـ Remotion لتوفير انتقالات ونصوص متحركة متجاوبة مع الأبعاد العمودية والأفقية.

### 4. Remotion Scenes
- **رابط المشروع:** [https://github.com/lifeprompt-team/remotion-scenes](https://github.com/lifeprompt-team/remotion-scenes)
- **الوصف:** مكتبة تضم أكثر من 200 مشهد حركي وجزيئات بصرية (Particle Effects) وتأثيرات خلفية سينمائية جاهزة للاستخدام في الفيديوهات.

### 5. Remotion Captions
- **رابط المشروع:** [https://github.com/remotion-dev/captions](https://github.com/remotion-dev/captions)
- **الوصف:** حزمة متخصصة لتحويل ملفات الترجمة (.srt أو JSON) إلى كابشن متحرك ومضيء متناسق مع التعليق الصوتي.

### 6. Remotion MCP App
- **رابط المشروع:** [https://github.com/mcp-use/remotion-mcp-app](https://github.com/mcp-use/remotion-mcp-app)
- **الوصف:** خادم بروتوكول MCP لعرض وتعديل فيديوهات Remotion لحظياً من داخل شات الذكاء الاصطناعي.

## 5. أدوات معالجة الصوت والترجمة (Audio & Captions Processing)

### 1. Fluent-FFmpeg
- **رابط المشروع:** [https://github.com/fluent-ffmpeg/node-fluent-ffmpeg](https://github.com/fluent-ffmpeg/node-fluent-ffmpeg)
- **الوصف:** مكتبة Node.js للتحكم بـ FFmpeg برمجياً لقس، دمج، وتعديل ملفات الصوت والـ MP3 وتنسيق الخلفيات الموسيقية لإنتاج الفيديوهات الطويلة.

### 2. Remotion Audiogram Template
- **رابط المشروع:** [https://github.com/remotion-dev/template-audiogram](https://github.com/remotion-dev/template-audiogram)
- **الوصف:** قالب معتمد لتحويل المسارات الصوتية والبودكاست إلى فيديوهات مرئية مع موجات صوتية متحركة وترجمة تلقائية.

### 3. Remotion Prompt to Video
- **رابط المشروع:** [https://github.com/remotion-dev/template-prompt-to-video](https://github.com/remotion-dev/template-prompt-to-video)
- **الوصف:** قالب توليد مخططات زمنية (Timeline.json) برمجياً لربط الصوت بالخلفيات والانتقالات بناءً على الوصف النصي فقط.
