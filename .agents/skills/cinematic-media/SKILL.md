# Cinematic Backgrounds & Media

حين يعمل الوكيل على خلفيات المشاهد (صور/فيديو/توليد AI لاحقاً)، اتبع هذا الـ skill. المرجع الحالي: `src/remotion/Shorts/Background.tsx` + `BackgroundMedia` في `types/shorts.ts`.

## الوضع الحالي (تحقق قبل الافتراض)

- اليوم: 5 ثيمات CSS فقط + طبقة `MediaLayer` اختيارية (`image`/`video` مع Ken Burns وتعتيم) + حبيبات SVG ثابتة. لا يوجد مزود AI أو Pexels بعد.
- أي مزود خارجي (Pexels/AI) **مقترح فقط** — واجهته يجب أن تبقى مستقلة عن المُصيّر (`ShortBackground` يقبل `media?: BackgroundMedia` ولا يعرف المصدر).

## متى يُفعَّل

- إضافة/تعديل خلفيات، مطابقة مشهد↔صورة، قص عمودي، blur/تعتيم، parallax، بدائل عند غياب الوسائط، تخزين مؤقت للوسائط، نسب المصدر والترخيص.

## ملفات يجب فحصها أولاً

- `src/remotion/Shorts/Background.tsx` — `THEMES`، `shortPalette()`، `GRAIN_URL`، `MediaLayer` (تكبير `interpolate(frame,[0,duration],[1,zoomTo])` + `objectFit:cover` + تعتيم `rgba(0,0,0,dim)`).
- `types/shorts.ts` — `BackgroundMedia {type, url, zoomTo 1–1.4 (افتراضي 1.08), dim 0–0.9 (افتراضي 0.45)}` قابل للـ null.
- `src/remotion/Shorts/ShortMain.tsx` — تمرير `backgroundMedia`، ترتيب الطبقات (خلفية → توهج → vignette → حبيبات → محتوى).
- `src/remotion/Shorts/WordCaptions.tsx` + `SceneCard.tsx` — مناطق النص التي يجب ألا تحجبها الخلفية.

## المدخلات والمخرجات

- **مدخلات**: نص المشهد + الثيم + اختياري `BackgroundMedia`. **مخرجات**: خلفية 1080×1920 تغطي الإطار (`cover`) مع تباين نص مضمون.
- **قاعدة التباين الثابتة**: أي خلفية جديدة تمر عبر `ShortPalette` القائم — لا ثيم جديد دون `bg/glow/accent/ink/muted/card/vignette` كاملة.

## سير العمل

1. **مطابقة المشهد**: كلمة مفتاحية واحدة من نص المشهد (≤280 حرف) → وصف بحث. لا ترسل النص كاملاً لمزود خارجي دون حاجة.
2. **القص العمودي**: المصدر الأفقي يُقص من المركز (`cover`) ما لم يُحدد focal-point صريح. `zoomTo` بين 1.0 و1.4 فقط — أعلى من ذلك يُبكسل في 1080p.
3. **التعتيم**: ابدأ بـ `dim=0.45`. اختبر فوق كل الثيمات الخمسة؛ الثيم الفاتح (`paper`, `ink=#1c1917`) يحتاج تعتيماً أعلى أو vignette أقوى.
4. **الحركة**: Ken Burns خطي عبر المدة الكاملة (`interpolate` واحد، لا `spring` لكل إطار). الفيديو الخلفي: `OffthreadVideo muted transparent={false}` + نفس التكبير.
5. **البديل**: `media=null` أو فشل التحميل → ثيم CSS + توهج + vignette + حبيبات. لا شاشة سوداء ولا إطار مكسور أبداً.
6. **الأداء**: الحبيبات SVG ثابتة (`opacity 0.045`, `mixBlendMode overlay`) — لا تُعِد رسمها كل إطار.

## المعايير

- الحتمية: نفس `media + frame` = نفس اللقطة. ممنوع عشوائية في التكبير/الإزاحة.
- `Img` للصور و`OffthreadVideo` للفيديو (لا `<video>` خام ولا `<img>` خام داخل Remotion).
- كل URL خارجي `z.string().url()` — تحقق schema قبل العرض.

## الأمان (سياسة URL صريحة)

- اسمح فقط بـ `https://` العامة. ارفض: `http://` غير المشفر، `localhost`، عناوين IP الخاصة (`10/8`، `172.16/12`، `192.168/16`)، `169.254.x` (metadata السحابة)، `file://`، `data:` غير الصور المصغرة الموثقة.
- أي توسعة جلب من طرف الخادم (Pexels/AI لاحقاً) يجب أن تمر بمراجعة `api-security-cost-protection/SKILL.md` (مهلة + حد حجم + نوع MIME مسموح).
- المفاتيح (Pexels/AI) خادم فقط — لا تظهر في `BackgroundMedia` ولا في props العميل.

## معالجة الأخطاء

| الحالة | السلوك |
|---|---|
| URL مكسور/404 | سقط إلى ثيم CSS + سجّل تحذيراً (لا تكسر الـ render) |
| فيديو بلا صورة غلاف | اعرض أول إطار مجمّد تحت التعتيم حتى يبدأ التدفق |
| أبعاد شاذة (مربع/أفقي ضيق) | `cover` + مركز — لا تشوّه النسبة (`contain` ممنوع هنا) |
| مزود خارجي فشل | بديل محلي فوري + إعادة واحدة فقط ثم بديل دائم لذلك المشهد |

## الاختبار (`bun test`)

- غطِّ: تحقق `BackgroundMedia` (رفض `zoomTo>1.4` و`dim>0.9` وURL غير صالح)، قيم `shortPalette` لكل ثيم (تباين `ink` فوق `bg`)، ثبات `interpolate` عند `frame=0` و`frame=duration`.
- اختبار بصري: لقطة لكل ثيم × (بلا media / صورة / فيديو) — راجعها عند تغيير أي طبقة.
- لا تدّعِ نجاح اختبار دون تشغيله.

## معايير القبول

- الخلفيات لا تحجب الكابشن (منطقة `SHORT_SAFE_BOTTOM` تبقى مقروءة).
- الوسيط المفقود ينتج بديلاً صالحاً دائماً.
- لا مزود جديد دون واجهة مستقلة عن المُصيّر (يمكن إضافة/إزالة Pexels/AI دون لمس `ShortMain`).
- لا وسائط غير مرخصة: كل مصدر خارجي موثق (مزود + شروط نسب) في وصف التغيير.

## القيود

- ممنوع تقديم Pexels كمولّد صور AI — هو مكتبة stock فقط. توليد AI يُقيَّم separately (الجودة/الترخيص/الزمن/التكلفة).
- ممنوع رفع `dim` فوق 0.9 أو `zoomTo` فوق 1.4 دون تحديث schema واختباراتها.
- ممنوع إضافة طبقة حركة لكل إطار تُعيد حساباً ثقيلاً (تقتل أداء الـ render).
